[Generate Placeholder Text](https://www.figma.com/community/plugin/1022744188040560638/Generate-Placeholder-Text) is a Figma plugin that speeds up UX/UI design workflows by making it easy to add placeholder text content in one click. As of October 2021 it has been installed over 600 times.

The plugin is available to install through Figma Community. Enjoy!

And if you're a developer, the [source code](https://github.com/rxnaij/generate-placeholder-text) is publicly available on GitHub.

If you have any feedback on how I can make the plugin better to suit your needs, feel free to get in touch via my site's contact form.
